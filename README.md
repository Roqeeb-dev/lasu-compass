# LASU Compass AI — Frontend

The AI-powered digital front desk for Lagos State University. This is the chat interface for LASU Compass AI, built for **GDG on Campus LASU — Build with Gemma 4**.

Students ask campus-related questions in natural language (course registration, clearance, SIWES, etc.) and receive answers grounded in LASU-specific documentation, generated by Gemma 4 via a RAG (retrieval-augmented generation) pipeline.

## Tech Stack

- **Framework:** Next.js (App Router) + TypeScript
- **Styling:** Tailwind CSS
- **Backend:** FastAPI + ChromaDB + Gemma 4 (see backend repo)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment Variables

Create a `.env.local` file in the project root:

```
NEXT_PUBLIC_API_URL=http://localhost:8000
```

## API Contract

The frontend communicates with the backend via a single endpoint.

**Request** — `POST /chat`

```json
{
  "query": "How do I register my courses?",
  "top_k": 4,
  "history": [
    { "role": "user", "content": "..." },
    { "role": "assistant", "content": "..." }
  ]
}
```

**Response**

```json
{
  "answer": "To register your courses...",
  "sources": [{ "source": "handbook.pdf", "section": "3.2 Clearance Process" }]
}
```
